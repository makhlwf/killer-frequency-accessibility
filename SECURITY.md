# Security policy

## Report a vulnerability

Use this repository's GitHub private vulnerability-reporting option when it is available. If it is unavailable, open a minimal issue asking for a private reporting route without posting exploit instructions, credentials, saves or proprietary game files. No response-time guarantee is offered.

## Scope

This native mod loads DLLs into the game process with the player's privileges. Use releases from the project, verify the published checksums and keep all paired files together. The release binaries are unsigned. Do not grant administrator privileges or disable antivirus software just to run a mod.

The local command file is a developer convenience for the same user, not an authenticated remote interface. Keep the installation folder under your control. Logs can contain private paths and story spoilers; redact them before filing an issue.

Supported testing is limited to the build identity and coverage described in supported-build.json and ACCESSIBILITY.md. A game patch or changed binary package requires new verification.
